# REST Ribbon

REST Ribbon is the first installable typeface drawn for the REST app, based on
the broad, flowing strokes of the REST R mark. The TTF is monochrome by design;
Flutter themes provide its color and any restrained glow treatment.

The family includes uppercase and lowercase letters, digits, punctuation, Latin-1,
Latin Extended-A accents, and the extra punctuation currently used by REST's
English, Norwegian, French, Spanish, and German translations.

Regenerate the bundled font with FontForge's Python interpreter:

```powershell
& 'E:\FontForgeBuilds\bin\ffpython.exe' 'E:\dev\repos\sleephelp\sleepapp\design\font\generate_rest_ribbon.py'
```

The generated app asset is `assets/fonts/RESTRibbon-Regular.ttf`.
