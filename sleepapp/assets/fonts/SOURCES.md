# Bundled font sources

Fonts are bundled for offline use. Keep the accompanying SIL Open Font License
files with these assets when distributing REST.

- Space Grotesk: existing project font; `SpaceGrotesk-OFL.txt`.
- Nunito variable, upright: downloaded 2026-11-19 from
  https://github.com/google/fonts/tree/main/ofl/nunito
  (`Nunito[wght].ttf`), with its unmodified `OFL.txt` saved as `Nunito-OFL.txt`.
- Cormorant Garamond variable, italic: downloaded 2026-11-19 from
  https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
  (`CormorantGaramond-Italic[wght].ttf`), with its unmodified `OFL.txt` saved as
  `CormorantGaramond-OFL.txt`.

R.E.S.T. uses Space Grotesk; the Tonight subtitle uses Cormorant Garamond italic;
the main UI uses Nunito.
