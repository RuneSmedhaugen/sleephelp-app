# Try the REST demo

**[Open the REST browser demo](https://runesmedhaugen.github.io/sleephelp-app/)**

You can open the link above on your phone, tablet, or computer. There is no
installation or GitHub account needed. The demo is interactive, but it does not
play sounds.

If you are viewing this folder on GitHub, select the link above to try REST.
You can also scan `rest-demo-qr.png` with your phone camera.
